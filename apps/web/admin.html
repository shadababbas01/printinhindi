Clear a user's plan

Ends any admin-granted plan override for this user right now, so their entitlement falls back to whatever's next in priority (a real subscription/purchase if they have one, otherwise Flex credits, otherwise none). This does not cancel a real Cashfree subscription or refund a purchase — use Cashfree for that.
