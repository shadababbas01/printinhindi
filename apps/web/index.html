सहायता / Help

1. .docx फ़ाइल अपलोड करें (Upload a .docx file).

2. अपने राज्य के अनुसार स्टाम्प पेपर प्रकार चुनें, या मैन्युअल रूप से हाशिया समायोजित करें।

3. टेस्ट पेज प्रिंट करें और सत्यापित करें कि रेखा स्टाम्प शीर्षक के नीचे संरेखित है।

4. "दस्तावेज़ प्रिंट करें" दबाएं और चेकलिस्ट पूरी करें।

Upload a .docx, pick your state's stamp paper preset (or set margins manually), print a calibration test page to verify alignment, then print the document.
